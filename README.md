New Zealand IMF Report Analysis
This notebook analyses New Zealand’s 2023 Article IV Consultation, IMF Country Report No. 23/309.
How to Run
1. Open 24074474.ipynb in Google Colab.
2. Upload the report as New Zealand.pdf.
3. Run all cells in order using a CPU runtime.
Internet access is required to download dependencies and models. No paid API key is needed.
Outputs
The notebook saves summaries, financial indicators, thematic analysis, RAG evaluations and a four-panel dashboard in its generated output folder.
Limitations
Some retrieval answers are incomplete. Automated judge scores require source verification. Inflation and policy-rate values use annual-average projections.
